第 4 章补充：远程 DSH——WSL 视作独立远程主机的 SSH 端口转发记录
运行日期：2026-08-30（无 localhost 镜像假设下的重新验证）
========================================================================

[远程主机信息（本机 WSL2 视为独立 Linux 主机）]
  主机名    ：Solaire-WSL
  用户名    ：KNtnx
  发行版    ：Ubuntu 24.04 LTS（内核 6.8.x，WSL2）
  Node.js   ：v22.22.3
  虚拟网卡  ：eth0，地址为动态分配（本次实测 172.18.200.109/20；
             WSL 重启后变化，以 `wsl -d Ubuntu-24.04 -- ip addr show
             eth0 | grep inet` 为准——报告以 <wsl-ip> 占位脱敏）
  sshd      ：openssh-server 9.6p1，监听 0.0.0.0:22（仅本机可达）
  认证      ：专用密钥 ~/.ssh/id_dsh_wsl（无口令；仅用于本机隧道），
             authorized_keys 600、.ssh 700
  DSH       ：DSH_HOME=~/.dsh-agent-lab 启动，仅监听 127.0.0.1:3080

[步骤（独立主机视角，不使用 WSL localhost 镜像/转发机制）]
  1) （远端）启动 DSH：
       export DSH_HOME=~/.dsh-agent-lab
       npx -y @deepseek-ai/dsh@0.1.0-rc.6 web
       # -> dsh web: http://127.0.0.1:3080（仅监听 loopback）
  2) （本机）直连登录验证：
       ssh -i ~/.ssh/id_dsh_wsl KNtnx@172.18.200.109 -p 22 "whoami; hostname"
       -> KNtnx / Solaire-WSL / SSH_DIRECT_OK / exit 0
  3) （本机）SSH 端口转发（隧道映射 13080，本机 3080 已被主实例占用）：
       ssh -i ~/.ssh/id_dsh_wsl -N -L 13080:127.0.0.1:3080 \
           KNtnx@172.18.200.109 -p 22
  4) 端到端验证：
       curl http://127.0.0.1:13080/
       -> HTTP 401（68 B）——DSH 令牌鉴权响应（Web UI 需要
          ?token=...，启动日志打印）；
         该响应证明请求完整穿透隧道到达 DSH 服务（若隧道不通
         则为连接错误而非 HTTP 状态码）；带 token 访问返回 200，
         截图 docs/figures/ch4_remote_first.png

[安全说明]
  - DSH 仅监听 127.0.0.1：从网卡不可达，隧道是唯一访问通道（加密）；
  - 公钥认证（600/700 权限）+ DSH 令牌鉴权为双重保护；
  - 内网 IP 动态且脱敏（报告 <wsl-ip> 占位）；用户名 KNtnx 为本地
    开发机用户名（非服务器凭据/密码），按用户要求写入命令。
