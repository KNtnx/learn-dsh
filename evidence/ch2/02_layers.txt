## 第一部分：基础概念篇

### 1. 什么是API？（用餐厅点餐来理解）
想象你去一家餐厅：
- **你**（程序员/学生）想吃东西（想要AI的帮助）
- **服务员**（API）负责传递你的需求到厨房
- **厨房**（大模型）准备好食物后，服务员再把食物端给你

**API（Application Programming Interface）** 就是这样的“服务员”，它让不同的程序能够互相交流。

### 2. 什么是大模型API？
大模型API是指：
- **OpenAI的ChatGPT API**
- **百度文心一言API**
- **阿里通义千问API** 
- **其他各类AI服务商的API**

你不需要自己训练模型，只需通过API发送请求，就能使用这些强大的AI能力。

### 3. 调用流程图解
```
你的程序 → 发送请求（包含你的问题） → API服务器 → 大模型处理 → 返回结果 → 你的程序显示答案
```

## 第四部分：理解请求参数

### 请求结构说明：
```python
{
    "model": "模型名称",      # 使用哪个AI模型
    "messages": [             # 对话历史记录
        {"role": "user", "content": "你的问题"},
        # 可以添加更多对话历史
    ],
    "temperature": 0.7,       # 创造性程度（0-2，越高越随机）
    "max_tokens": 100,        # 回复最大长度（1个汉字≈2-3个token）
    "top_p": 1.0,             # 另一个控制随机性的参数
    "frequency_penalty": 0.0  # 减少重复内容
}
```

### 角色说明：
- **user**：用户输入（你的问题）
- **assistant**：AI的回复
- **system**：系统提示（告诉AI它是谁，比如“你是一个中文老师”）

## 第五部分：实战练习

### 练习1：创建你自己的第一个聊天机器人
```python
def chat_with_ai(user_input):
    """简单的聊天函数"""
    try:
        response = openai.ChatCompletion.create(
            model="gpt-3.5-turbo",
            messages=[
                {"role": "system", "content": "你是一个友好的学习助手，用简单中文回答问题。"},
                {"role": "user", "content": user_input}
            ],
            temperature=0.7,
            max_tokens=200
        )
        return response.choices[0].message.content
    except Exception as e:
        return f"出错了：{str(e)}"

# 使用示例
print(chat_with_ai("Python适合初学者吗？为什么？"))
```

try:

## 常见问题解答（FAQ）

**Q：我没有信用卡，怎么获取API额度？**
A：部分国内厂商支持支付宝付费，或者使用Google Colab等平台自带的免费额度。

**Q：调用时出现“rate limit exceeded”错误怎么办？**
A：这是请求太频繁了，等待60秒再重试，或减少请求频率。

**Q：为什么我的回复很慢？**
A：1) 网络问题；2) `max_tokens`设置太大；3) 使用的模型较复杂。

**Q：我可以把API密钥用在多个项目吗？**
A：可以，但建议为不同项目创建不同的密钥，便于管理和撤销。

# 大模型 API 调用入门教程

## 一、背景说明

本教程旨在为零基础学生提供一个使用 Python 调用大语言模型 API 的快速入门指南。你将学习如何通过编程方式，向一个真实的大模型（如 Kimi）发送对话请求，并获取其生成的回答。

**核心概念解释：**
1.  **API (应用程序编程接口)**：你可以将其理解为一个“服务窗口”。大模型服务商通过这个窗口对外提供功能，你只需要按照约定的“规则”（即 API 文档）发送请求，就能获得结果，而无需关心模型内部是如何运行的。
2.  **API Key**：相当于你调用 API 的“钥匙”或“密码”。它用于验证你的身份并记录用量，确保只有授权用户才能使用服务。申请后请妥善保管，不要泄露。
3.  **HTTP POST 请求**：这是向服务器发送数据的常用方式。在调用大模型 API 时，你需要将对话内容通过 POST 请求发送到指定的 URL 地址。
4.  **兼容性**：值得庆幸的是，包括 Kimi 在内的许多国内大模型平台，其 API 协议都与 OpenAI 兼容。这意味着，为一个平台编写的代码，只需修改少量配置（如 API 地址、密钥、模型名）即可用于另一个平台，极大提升了代码的复用性。

## 三、实验步骤

### 实验1：编写第一个调用脚本

创建一个名为 `call_kimi.py` 的 Python 文件，并输入以下代码。

```python
import requests
import json

# 1. 配置你的 API 信息
api_key = "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # 替换为你的真实 API Key
base_url = "https://api.moonshot.cn/v1/chat/completions"

# 2. 构建请求头 (Headers)
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {api_key}"
}

# 3. 构建请求体 (Request Body)
payload = {
    "model": "moonshot-v1-8k",  # 使用 Kimi 的模型，例如 8K 版本
    "messages": [
        {
            "role": "system",     # `system` 用于设定AI的角色或行为准则
            "content": "你是一个友好的AI助手。"
        },
        {
            "role": "user",       # `user` 代表用户发出的消息
            "content": "你好，请用一句话解释什么是大模型API。"
        }
    ],
    "temperature": 0.3,          # 控制输出随机性，值越低越确定
    "max_tokens": 500            # 本次回复允许生成的最大token数
}

# 4. 发送 POST 请求
try:
    response = requests.post(
        url=base_url,
        headers=headers,
        data=json.dumps(payload)  # 将 payload 字典转换为 JSON 字符串
    )
    
    # 5. 处理响应
    response.raise_for_status()  # 如果请求失败 (HTTP 状态码非 200)，则抛出异常
    result = response.json()     # 将返回的 JSON 字符串解析为 Python 字典
    
    # 6. 提取并打印结果
    assistant_message = result['choices'][0]['message']['content']
    print("Kimi 的回答：")
    print(assistant_message)
    print("\n--- 原始响应数据 ---")
    print(json.dumps(result, ensure_ascii=False, indent=2)) # 格式化打印完整响应

except requests.exceptions.RequestException as e:
    print(f"请求发生错误: {e}")
    if hasattr(e, 'response'):
        print(f"响应内容: {e.response.text}")
except KeyError as e:
    print(f"解析响应时出错，可能缺少字段: {e}")
    print(f"收到的响应: {result}")
```

**代码关键点解释：**
*   **`model`**：指定你想要调用的模型版本。Kimi 提供了不同上下文长度的模型。
*   **`messages`**：对话历史列表。`role` 定义了消息来源（`system` 系统指令，`user` 用户，`assistant` 模型历史回复）。API 会根据这个列表来理解上下文。
*   **`temperature`**：一个 0-2 之间的浮点数，值越大输出越随机/创新，值越小输出越保守/确定。
*   **`max_tokens`**：限制模型单次回复的最大长度。对于推理模型，建议预留足够空间（如 >= 1000）。
*   **错误处理**：使用了 `try-except` 块来捕获网络错误或 API 返回的错误，并打印有意义的错误信息。

### 实验2：测试与调试

3.  观察控制台输出。你应能看到模型的回答以及完整的 JSON 响应结构。

**常见问题排查：**
*   **`401 Unauthorized` 错误**：通常是 API Key 错误或未正确放在 `Authorization` 头中。
